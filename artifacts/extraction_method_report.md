# รายงานวิธีสกัดข้อมูล — OCR vs Text Layer

เอกสารนี้แยกให้ชัดว่า **ส่วนไหนของระบบใช้ OCR และส่วนไหนใช้ text layer** 
ตั้งแต่ระดับหน้า ไปจนถึงข้อมูลปลายทางที่ RAG ใช้ตอบคำถาม

## สรุปสำหรับนำเสนอ

- เอกสาร **14 เล่ม / 3,689 หน้า**
- **text layer: 2,739 หน้า (74.2%)** — PDF ที่ฝังข้อความมาแล้ว
- **OCR (Tesseract 5): 950 หน้า (25.8%)** — หน้าที่เป็นภาพสแกน

ข้อมูลปลายทางที่ระบบใช้ตอบคำถาม:

| ข้อมูล | จาก text layer | จาก OCR | สัดส่วน OCR |
|---|---:|---:|---:|
| chunk (ฐานความรู้ RAG) | 8,493 | 3,094 | 26.7% |
| รายวิชา (structured) | 819 | 600 | 42.3% |

**ประเด็นสำคัญ:** OCR ไม่ใช่ส่วนประกอบเสริม — มันเป็นแหล่งของรายวิชาถึง 42% และของ chunk 27% 
ถ้าไม่มี OCR ระบบจะขาดข้อมูลส่วนนี้ทั้งหมด

## 1. ระบบตัดสินใจเลือกวิธีสกัดอย่างไร

ทุกหน้าถูกวัดด้วย `page_metrics` แล้ว route อัตโนมัติ (`katrag/ingest/page_router.py`) ไม่ได้กำหนดด้วยมือ

### ตัวชี้วัดที่ใช้ตัดสิน — ค่าเฉลี่ยของสองกลุ่ม

| ตัวชี้วัด | หน้าที่ใช้ text layer | หน้าที่ส่งเข้า OCR | ตีความ |
|---|---:|---:|---|
| จำนวนหน้า | 2,739 | 950 | |
| อักขระที่ดึงได้จาก text layer | 1,264 | 94 | หน้า OCR แทบไม่มีข้อความฝังมา |
| สัดส่วนพื้นที่ภาพ | 0.340 | 0.788 | หน้า OCR เป็นภาพเกือบทั้งหน้า |
| คำในคลังศัพท์หลักสูตร | 10.2 | 3.0 | text layer เจอคำเฉพาะทางมากกว่า |

เกณฑ์หลักคือ **ข้อความฝังน้อย + พื้นที่ภาพสูง** → ส่งเข้า OCR

## 4. ขอบเขตของการวัดความแม่นยำ (ข้อจำกัดที่ต้องระบุ)

Ground truth ของอาจารย์เป็น **แผนการเรียน** ของ 4 หลักสูตร (AIT 2566, BIT 2565, DSBA 2565, IT 2565)
ซึ่งตารางแผนการเรียนของทั้ง 4 เล่มนี้อยู่ในหน้าที่ **มี text layer** 

- รายวิชาในหลักสูตรที่มี GT: จาก text layer 272 / จาก OCR 539
- รายวิชาที่ **จับคู่กับ GT ได้จริง** (272 วิชา): มาจาก text layer ทั้งหมด, จาก OCR 0 วิชา

**สิ่งที่สรุปได้:**

1. ตัวเลข field accuracy ที่รายงาน (ชื่อวิชา 0.92-0.98, หน่วยกิต 0.996, ปี/ภาค 0.95) เป็นการวัด **คุณภาพของ text layer + ขั้นตอน parsing** ไม่ใช่คุณภาพของ OCR
2. การเปลี่ยน OCR engine (เช่น Typhoon OCR) **จะไม่ทำให้ตัวเลขชุดนี้เปลี่ยน** เพราะข้อมูลที่วัดไม่ได้ผ่าน OCR
3. แต่ OCR ยัง**รับผิดชอบข้อมูลจำนวนมากที่วัดตรง ๆ ไม่ได้** — 600 รายวิชา และ 3,094 chunk (วิชาเลือก วิชาศึกษาทั่วไป คำอธิบายรายวิชา ภาคผนวก)
   ส่วนนี้ไม่มี GT จึงประเมินได้เพียงโดยอ้อม ผ่าน OCR confidence (เฉลี่ย 0.85-1.00) และ out-of-charset ratio

**ถ้าจะวัด OCR โดยตรง** ต้องมี GT ระดับข้อความของหน้าที่ผ่าน OCR (จะได้ค่า CER/WER) ซึ่งตอนนี้ยังไม่มี — `katrag/eval/metrics.py` มีฟังก์ชัน `page_cer` รอใช้อยู่แล้ว
