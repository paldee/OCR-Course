# รายงานการประเมิน OCR — Jingjok-Thorius

ประเมิน 3 ระดับ: **page level** (วิธีสกัด/คุณภาพหน้า), **field level** 
(เทียบฟิลด์รายวิชากับ ground truth ของอาจารย์), **category level** (recall ต่อหมวดวิชา)

Ground truth เปิดแบบ read-only เท่านั้น ไม่มีการเขียนกลับหรือใช้เป็นแหล่งคำตอบ

**อ่านค่า:**

- `page quality` — คะแนนคุณภาพหน้า (0-1) จาก char count, สัดส่วนภาพ, คำในคลังศัพท์เฉพาะทาง
- `out-of-charset` — สัดส่วนอักขระที่อยู่นอกชุดอักขระที่คาดหวัง (ยิ่งต่ำยิ่งดี; สูง = OCR เพี้ยน)
- `OCR conf` — ค่าความมั่นใจของ Tesseract เฉพาะหน้าที่ผ่าน OCR (— = ไม่มีหน้าที่ต้อง OCR)

**เหตุผลการเลือกวิธี:** ระบบ route แต่ละหน้าอัตโนมัติ (`page_router`) — หน้าที่มี text layer 
คุณภาพดีใช้ text layer ตรง ๆ (แม่นกว่าและเร็วกว่า) หน้าที่เป็นภาพสแกน/text layer เสียจึงส่งเข้า OCR

**ขอบเขตของตัวเลขในหัวข้อ 2:** รายวิชาที่จับคู่กับ GT ได้ทั้ง 272 รายการ มาจากหน้า **text layer** ทั้งหมด (จากหน้า OCR = 0)
เพราะ GT ของอาจารย์คือ *ตารางแผนการเรียน* ซึ่งในทั้ง 4 เล่มอยู่ในหน้าที่ PDF ฝังข้อความมาแล้ว

ดังนั้นต้องตีความให้ถูก:

- ตัวเลข field accuracy ข้างต้นวัด **คุณภาพ text layer + ขั้นตอน parsing** 
  ไม่ได้วัดคุณภาพของ OCR
- การเปลี่ยน OCR engine จะ **ไม่ทำให้ตัวเลขชุดนี้เปลี่ยน** เพราะข้อมูลที่วัดไม่ผ่าน OCR
- แต่ **ไม่ได้หมายความว่า OCR ไม่สำคัญ** — OCR เป็นแหล่งของรายวิชา 600 จาก 1,419 รายการ (42%) และ chunk 3,094 จาก 11,587 (27%) ทั่วทั้งฐานข้อมูล 
  ส่วนนั้นเป็นวิชาเลือก วิชาศึกษาทั่วไป และคำอธิบายรายวิชา ซึ่ง GT ไม่ครอบคลุม จึงวัดตรง ๆ ไม่ได้
