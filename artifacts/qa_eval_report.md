# รายงานผลทดสอบคำถาม 3 ระดับ — KatRAG-lite

ระบบยิงคำถามเข้า `POST /ask` โดยส่งเฉพาะ `question` + `program`
**ไม่มีการส่งเฉลยหรือคำอ้างอิงเข้าไปในระบบ/prompt** (บังคับด้วย assertion ใน `qa_eval.py`)

`auto` เป็นเพียงการคัดกรองเบื้องต้น (ตรวจว่าคำสำคัญปรากฏในคำตอบไหม)
คะแนนจริงตามใบเสนอโครงการต้องให้ **ผู้ตรวจกาช่อง** ว่าคำตอบถูก + อ้างอิงถูก
